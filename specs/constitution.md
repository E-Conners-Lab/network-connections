# Constitution

1. Teach real subnetting. Every rule the game enforces is a rule a router enforces (alignment, no overlap, usable-host counts).
2. Static and offline. HTML, CSS and ES modules only. No build step, no dependencies, no network, no API key.
3. Say why. Every rejection explains the rule that was broken, with the actual addresses.
4. Pure logic is separate from the UI so it can be tested without a DOM.
5. Be honest about simplifications (see spec, "Out of scope").
