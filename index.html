Address Space Packer

Merge the address space back together.

  • Slide every block with the arrow keys (or WASD, the arrow buttons, or a swipe). A new block arrives after each move.
  • Merge siblings. Two blocks merge only if they are the two halves of the same bigger block: same size, side by side, and the lower one starts on a multiple of the bigger block's size.
  • Example: 10.0.0.0/28 + 10.0.0.16/28 = 10.0.0.0/27. But 10.0.0.16/28 + 10.0.0.32/28 cannot merge, because a /27 cannot start at .16.
